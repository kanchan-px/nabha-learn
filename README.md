# Nabha Learn

Offline-first digital learning platform for rural government schools, built for low-connectivity, low-end Android environments.

## Project Structure

This is a monorepo containing three independent applications:

- `backend/` — Node.js + Express + TypeScript REST API, PostgreSQL (via Prisma)
- `web/` — React + TypeScript admin/teacher dashboard (Vite)
- `mobile/` — React Native (Expo) student app with offline-first support
- `docs/` — architecture decisions, API documentation, design notes

## Getting Started

Setup instructions for each app live in that app's own README (added as each is scaffolded).
